✨ Showpieces
*************

Bertini 2 solves and *tracks* — and tracking is a moving picture.  The **showpieces** are
deliberately beautiful renders that put the library's machinery on stage: parameter homotopy,
adaptive-precision path tracking, endgames, and the observers that watch every step.  Each one is
generated entirely from real tracked data (no illustrations), so it doubles as a worked, runnable
example of the API.

Unlike the :doc:`tutorials </tutorials/tutorials>`, showpieces are heavy hero renders rather than
doctested code blocks: the page embeds a pre-rendered image and shows the code beside it.  They are
raster (PNG) — a 3-D render has no meaningful vector form — and are regenerated, like every doc
figure, through ``tools/refresh_doc_artifacts.py`` so they stay current with the library.
