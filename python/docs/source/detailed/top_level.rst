🔝 bertini

Convenience
------------

For your convenience, these things have been placed in the root level `bertini` namespace:

* :class:`~bertini.system.System`
* :class:`~bertini.function_tree.symbol.Variable`
* :class:`~bertini.function_tree.VariableGroup`

There's not a whole lot else at this level.  Bertini2's Python package mostly exists in submodules, to help things be organized.
