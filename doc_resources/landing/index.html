Command-line executable

Bertini 2 ships a standalone executable, bertini2, that reads the classic Bertini input-file format and solves zero-dimensional polynomial systems. 

bertini2 [options] [input_file]   # input_file defaults to "input"
bertini2 --help                   # full usage
bertini2 --version                # library and dependency versions

Parallelism

Two orthogonal parallelism layers are available when the library is built with MPI (MPI is auto-detected at configure time and enabled by default when found):

MPI ranks
Distribute paths across multiple processes. Pass --bind-to none so each rank can use all its cores. 
mpirun --bind-to none -n N bertini2 input
Threads per rank
Each MPI rank tracks multiple paths concurrently using std::thread (not OpenMP). The thread count is read from the environment variable OMP_NUM_THREADS, which HPC schedulers such as SLURM set automatically from --cpus-per-task. Set it manually if running outside a scheduler: 
OMP_NUM_THREADS=T mpirun --bind-to none -n N bertini2 input
Total parallel capacity = N ranks × T threads/rank. OMP_NUM_THREADS defaults to 1 when unset.
