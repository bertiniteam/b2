Detailed Description

template<typename TrackerType, typename EndgameType, typename SystemType>
struct bertini::algorithm::AlgoTraits< HomotopySolver< TrackerType, EndgameType, SystemType > >

specify the traits for the algorithm.

this is why we need the forward declare. ZeroDimSolver derives from HomotopySolver (and so inherits its Configured base), so only HomotopySolver needs traits specialized here.
