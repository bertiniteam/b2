Detailed Description

A matrix of expression-tree nodes (the symbolic Jacobian), stored row-major.

Unlike the numeric Mat<T> Jacobian, this carries the partial-derivative expressions themselves (one Node per entry). entries has rows*cols elements in row-major order (entries[i*cols + j] is row i, column j). See SymbolicJacobian.
