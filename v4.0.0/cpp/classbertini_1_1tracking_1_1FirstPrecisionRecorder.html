Detailed Description

template<class TrackerT>
class bertini::tracking::FirstPrecisionRecorder< TrackerT >

Observer that records the starting precision and the first precision increase of each track: each call to TrackPath, from its start.

A track begins with the tracker's Initializing event, which comes before the start point is refined, so an increase that the refinement needs counts as the track's first. The record starts afresh with each track, and the observer stays attached: attach it once and it reports every track, including one whose initialization fails.

For a whole path, which the endgame tracks in many calls, see PathPrecisionRecorder.
