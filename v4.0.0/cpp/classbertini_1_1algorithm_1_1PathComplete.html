template<class ObservedT>
SuccessCode bertini::algorithm::PathComplete< ObservedT >::Outcome ( ) const
inline

How this path ended.

The endgame's code for a path that reached the endgame, and the pre-endgame code for one that did not get that far – in both cases the code already written to this path's own metadata slot. Carried on the event so a watcher can tally outcomes as they happen, rather than reaching into metadata another thread is still filling in.

Success here is not the same as a finite solution: classification (finite, at infinity, singular) happens after every path is done.
