Detailed Description

Small shared helpers for the per-block Describe methods – the human-facing printing of a block-composed System.

Each block prints the rows it owns, labelled by a running global index f_k. Two levels: terse (default) uses placeholder symbols for matrices/coefficients so only the structure shows; verbose reveals the actual numbers. This output is for reading, not for re-parsing.
