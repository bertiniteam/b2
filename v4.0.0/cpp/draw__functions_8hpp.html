Detailed Description

Dependency-free declarations of the pinned draw primitives (ADR-0044).

The foundational headers (num_traits, double_extensions) need double draws from the per-thread pinned stream but must not include the full derive.hpp (which needs the multiprecision types those headers define). These free functions break the cycle; definitions live in src/records/derive.cpp.
