Detailed Description

template<typename, typename = void>
struct bertini::blocks::is_block< typename, typename >

Detection trait: does B satisfy the evaluation-block contract?

Checks the complex_dbl instantiation of the templated eval entry points plus the metadata methods. Adding a non-conforming type to the block variant then fails a one-line static_assert instead of producing a deep template error at the visit site.
