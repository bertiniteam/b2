int b )
inlinestatic

Combine two per-function degrees, propagating the not-a-polynomial sentinel.

A blend of functions is a polynomial only when every operand is, so a -1 from any operand must survive. A plain maximum starting at zero silently turned it into a claim of degree zero, which is how a transcendental homotopy came to report itself as a constant.

◆ Degrees() [1/2]

template<typename SystemT>
std::vector< int > bertini::blocks::BlendBlock< SystemT >::Degrees ( ) const
inline

The blend c_0(t)f_0 + c_1(t)f_1 + ... has, per function, the max degree of its operands in the space variables (the t-coefficients are constant in space).

A function that is not a polynomial reports -1, and that answer propagates through the blend.
