Print one (complex_mp) coefficient compactly: a real prints as its real part, a pure imaginary as b*i, otherwise as (a+b*i).

sig controls the digit count (see FmtReal); the default of 0 keeps full precision for any caller that does not opt into the short form.

◆ kTerseRowCap

size_t bertini::blocks::describe_detail::kTerseRowCap = 10
inlineconstexpr

How many function rows a block lists in terse (non-verbose) describe before truncating with a ... (k more ...) line.

Keeps a large system (e.g. a slice with many forms) from flooding the terminal now that the terse output carries actual coefficients; verbose prints every row.
