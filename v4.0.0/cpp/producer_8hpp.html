Detailed Description

Which software produced a record: name, version, and source commit, for the producer field of run headers.

An archive read in ten years should say which binary wrote it. The producer is DESCRIPTIVE only – it is never part of the ask identity, so a newer build answering the same ask still recalls the old answer rather than recomputing.
