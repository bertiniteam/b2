Detailed Description

Result struct used in the manager-worker MPI protocol for ZeroDim.

In the unified speculative-full-path model a worker executes one WHOLE path (pre-endgame + endgame), so the protocol is a single task/result pair: task = SolnIndT path index result = FullPathResult<ComplexT> (boundary data + final solution + endgame metadata)

FullPathResult carries Boost.Serialization support so Boost.MPI can transmit it via the existing serialization for Eigen vectors and arbitrary-precision types.
