Detailed Description

Emit a System (and, with a config, a whole solve) as a Bertini 1 classic input file.

The classic parser (io/parsing) reads Bertini 1 input files; this is its inverse. Emitting a CONFIG ... END;\nINPUT ... END; file lets the same problem be run in Bertini 1 for cross-validation – e.g. to check whether a path-crossing or a root count reproduces across implementations (modulo each one's random start system).

The emitted text is round-trip-safe: parsing it back with bertini::System's classic constructor yields an equivalent system.
