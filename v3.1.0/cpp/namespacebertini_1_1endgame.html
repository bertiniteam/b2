Vec< ComplexT > bertini::endgame::HermiteInterpolateAndSolve ( ComplexT const &  target_time,
const unsigned int  num_sample_points,
const TimeCont< ComplexT > &  times,
const SampCont< ComplexT > &  samples,
const SampCont< ComplexT > &  derivatives,
ContStart  shift_from = ContStart::Back 
)

Estimates the root to interpolating polynomial.

Input: target_time is the time value that we wish to interpolate at. samples are space values that correspond to the time values in times. derivatives are the dx_dt or dx_ds values at the (time,sample) values.

Output: Since we have a target_time the function returns the corrsponding space value at that time.

Details: We compare our approximations to the tracked value to come up with the cycle number. Also, we use the Hermite interpolation to interpolate at the origin. Once two interpolants are withing FinalTol we say we have converged.

Parameters
target_timeThe time value that we wish to interpolate at.
num_sample_pointsThe number of (time, sample) points used in the interpolation.
timesThe time values of the samples used for interpolation.
samplesThe space values corresponding to the time values in times.
derivativesThe dx/dt (or dx/ds) values at the (time, sample) points.
shift_fromWhich end of the sample containers to interpolate from.
Template Parameters
ComplexTThe complex number type.
