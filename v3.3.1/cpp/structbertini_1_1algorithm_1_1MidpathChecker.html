Detailed Description

template<typename RealT, typename ComplexT, typename MetaDataType>
struct bertini::algorithm::MidpathChecker< RealT, ComplexT, MetaDataType >

Detects whether any solution paths crossed during tracking, before the endgame.

Compares the solution points at the endgame boundary (with a relaxed tolerance) and records the paths that coincide, so the caller can rerun the offending paths.

Template Parameters
RealTThe real number type.
ComplexTThe complex number type.
MetaDataTypeThe per-solution metadata type carried in the boundary data.
