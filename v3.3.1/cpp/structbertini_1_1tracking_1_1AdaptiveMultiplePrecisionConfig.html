They are nonetheless initialized here so that a default-constructed config is fully deterministic: epsilon takes the single-variable value ( ), and Phi/Psi are derived from the default bounds so the object is internally consistent. Leaving them uninitialized produced garbage (e.g. NaN) that broke value comparison and pickle round-tripping.
