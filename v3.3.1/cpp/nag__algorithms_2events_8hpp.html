Detailed Description

Events emitted by the higher-level algorithms (e.g.

ZeroDim) during a solve.

These are emitted on a non-templated emitter base (e.g. AnyZeroDim) so that a single observer type can watch every templated instantiation of the algorithm. An observer recovers the concrete algorithm (and its full interface) from the event's Get(): in C++ via dynamic_cast, in Python automatically via RTTI to the most-derived registered type.
