Detailed Description

template<typename TaskT, typename ResultT, typename StateFactory, typename TrackFn>
class bertini::parallel::WorkerThreadPool< TaskT, ResultT, StateFactory, TrackFn >

Thread pool for parallel path tracking within a single MPI worker rank.

Template Parameters
TaskTTask type received from the MPI manager.
ResultTResult type sent back after tracking.
StateFactoryCallable () -> StateT: constructs a per-thread state struct (e.g. containing a System copy + Tracker copy) once at thread startup.
TrackFnCallable (StateT&, TaskT const&) -> ResultT: tracks one path using the thread-local state.

The StateFactory approach sidesteps the "tracker holds a reference to an external System" issue: each thread owns its state struct, so System and Tracker lifetimes are co-managed.
