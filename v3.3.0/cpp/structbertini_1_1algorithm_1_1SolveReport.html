Detailed Description

A concise, human-readable summary of a zero-dimensional solve: how every path ended up, and – crucially – whether any path was lost.

A raw solution count can lie: if a near-singular path fails to track, a genuine root is silently missing and the count comes back short. This report buckets every endpoint into a finite solution, a clean divergence, or a genuine FAILURE (the tracker gave up), records the failures by their named SuccessCode, and exposes all_paths_resolved as the one-line health check.
