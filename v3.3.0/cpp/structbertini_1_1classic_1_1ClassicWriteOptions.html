Detailed Description

Tracking / precision settings to emit in the CONFIG section, in Bertini 1 terms.

Defaults mirror Bertini 2's defaults for an adaptive zero-dim solve, so the emitted file runs the same problem with the same knobs in Bertini 1 (the random start system aside).
