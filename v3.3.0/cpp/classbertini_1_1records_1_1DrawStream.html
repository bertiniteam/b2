Detailed Description

A deterministic, fully-specified random stream (SHA-256 counter mode).

One per thread in practice (see ThreadDrawStream); reseeded by the same (master, domain, index) tuples the legacy engine seeding uses, so setup / per-path / worker domain separation is preserved.
