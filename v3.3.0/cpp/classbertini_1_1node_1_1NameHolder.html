Detailed Description

Capability class for things which have a name.

Deliberately NOT a Node: classes that need a name alongside a different primary base (e.g. special_number::Pi, which is a Number) inherit this without creating a diamond in the Node hierarchy.

Mixin holding a name, shared by named nodes without forming a diamond in the hierarchy.
