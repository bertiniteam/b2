Detailed Description

A block of system functions, each a product of linear forms.

Value-in / value-out: evaluation takes the variable vector and writes into a caller- provided segment, so the block is self-contained and unit-testable without a System.

The master (highest-precision) coefficient matrices, one per function; matrix i is (number of factors of f_i) x (num_vars+1), the last column being the constant/augmenting term.

Exposed so the function-tree expansion (System::ExpandToFunctionTree) can rebuild f_i = prod_r L_r.
