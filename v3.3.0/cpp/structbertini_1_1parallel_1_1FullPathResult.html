Detailed Description

template<typename ComplexT>
struct bertini::parallel::FullPathResult< ComplexT >

Result of executing one WHOLE path: start -> endgame boundary -> target.

The single result type for the speculative-full-path model. A worker carries a path through both the pre-endgame tracking and the endgame, so this bundles the boundary data (needed for the manager's midpath/crossing check) together with the final solution and all endgame metadata. The work item that produces it is a StartPointTask (path index + rank 0's start point).
