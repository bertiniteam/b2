◆ EffectiveThreadCount()

unsigned bertini::parallel::EffectiveThreadCount ( unsigned  configured = 0)
inline

Resolve a configured thread count to the number of worker threads to actually spawn.

Precedence (highest first):

  1. The OMP_NUM_THREADS environment variable, if set to an integer >= 1. HPC schedulers (SLURM) set this from –cpus-per-task, so honoring it keeps the MPI+threads hybrid and the standalone threaded solve behaving the same under a job allocation.
  2. The configured value, if >= 1 (e.g. a num_threads config knob set by the user).
  3. std::thread::hardware_concurrency() when configured == 0 ("auto").

Always returns >= 1 (a return of 1 means "run serially, no pool"). hardware_concurrency() can report 0 on exotic platforms; we clamp that to 1.
