Detailed Description

template<typename SystemType>
struct bertini::algorithm::zero_dim_detail::OwnedHomotopy< SystemType >

Owns and builds the target / start system / homotopy for a zero-dim solve.

Constructed as the FIRST base of ZeroDimSolver – before the HomotopySolver engine base, which holds references into these systems – so the homotopy is fully formed before the engine reads it. This holds the system-building half of the algorithm, plus the feasibility / rank checks the algorithm owns. Members carry an owned_ prefix so they do not collide with the engine base's reference members.

◆ RankCheck()

template<typename SystemType >
void bertini::algorithm::zero_dim_detail::OwnedHomotopy< SystemType >::RankCheck ( ) const
inlineprotected

Reject a square target whose solution set is still positive-dimensional.

ConsistencyCheck only counts equations; a system can be square yet positive-dimensional (e.g. a repeated equation). At a generic point a zero-dimensional system has a full-rank n x n Jacobian, so a rank-deficient Jacobian there means no isolated solutions. Runs only when the (natural, pre-homogenize) system is square; projective/structured inputs whose Jacobian is not n x n are left to ConsistencyCheck.

◆ SquareUp()

template<typename SystemType >
void bertini::algorithm::zero_dim_detail::OwnedHomotopy< SystemType >::SquareUp ( )
inlineprotected

If the target is over-determined (more equations than the affine dimension), replace it with n generic combinations (System::Randomize) so a start system can track it.

The randomized system's isolated solutions contain the original's plus extraneous ones; the original system is kept (original_natural_target_) so ZeroDimSolver can filter those out.
