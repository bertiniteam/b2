Detailed Description

template<class ObservedT>
class bertini::algorithm::PathStarted< ObservedT >

The algorithm is beginning work on one solution path, carrying its index.

Between this and the matching PathComplete, the algorithm runs everything for that path – the main homotopy track and any endgame sub-tracks – so an observer can group them together as one complete solution path.

template<class ObservedT >
Observable const * bertini::algorithm::PathStarted< ObservedT >::Tracker ( ) const
inline

The tracker that actually executes this path.

In a serial solve this is the solver's member tracker; in a threaded solve it is the thread-local tracker clone that owns the path (Observable copies inherit no observers, so the member tracker would see nothing). A meta-observer that wants per-path tracking data must attach its sub-observer here, NOT to solver.GetTracker(). AddObserver is a const method, so observers can still be attached through this const handle. May be null if the emitter supplied no tracker.
